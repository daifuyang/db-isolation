# db-isolation

ECS 数据库按应用隔离的标准规范与工具集。

## 核心原则

**最小爆炸半径**：每个应用拥有独立的库 + 独立的低权限账号。
AI 或应用出问题的影响半径 = 自己的库，碰不到其他库。

## 设计目标

- 一个应用 = 一个库 + 一个专属账号
- 账号权限刚好够用，不给 DDL（除非业务需要）
- AI 不持有 root 凭证，只能调用建库脚本
- 数据库端口不暴露公网，仅 SSH 隧道 + 本地访问
- 所有建库/改表操作有审计日志

## 目录结构

```
db-isolation/
├── scripts/     建库、改密、审计等运维脚本
├── config/      权限模板、连接串模板
├── docs/        规范文档、操作手册
└── logs/        审计日志（gitignored）
```
